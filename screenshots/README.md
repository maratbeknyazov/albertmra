## Слайдер

`index.html` — готовая галерея: один файл, без зависимостей и сборки.

- стрелки, клавиши ← →, свайп, миниатюры, счётчик и автопрокрутка с паузой;
- цвет подсветки меняется под каждый проект (акцент задан в данных слайда);
- адаптив: на узких экранах изображение и текст складываются в колонку.

### Как вставить в свой сайт

1. Скопируйте папку `screenshots` в проект CV-сайта (например, в `public/`).
2. Откройте `index.html` — весь код в одном файле, его можно целиком перенести в нужную страницу или разнести на HTML/CSS/JS.
3. В массиве `SLIDES` поменяйте пути к картинкам, тексты и, если платформы уже задеплоены, поле `url` — тогда в панели появится ссылка «Открыть платформу».

```js
{
  id: "freight-desk",
  title: "Freight Desk",
  kicker: "Логистика США",
  image: "./logistics-hero.png",
  url: "https://your-deploy.vercel.app", // пусто = ссылки нет
  ...
}
```

### Пересъёмка

Кадры сняты headless Chrome при `--window-size=1440,900` и `--force-device-scale-factor=1`. Для нового кадра достаточно заменить PNG с тем же именем — разметка и стили трогать не нужно.
